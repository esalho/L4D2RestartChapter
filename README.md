# L4D2 Vote Restart

A SourceMod plugin for Left 4 Dead 2 that lets players vote to restart the current chapter. It is intended for custom campaigns where a map bug blocks progress, so the team can retry the chapter instead of restarting the whole campaign. It currently works by killing the characters to trigger chapter restart. 

## Usage

Type `!restart` in chat to start a vote. The chapter restarts only if every active (non-AFK) human player votes yes.

The plugin works in non-PvP modes only. It is disabled in Versus and Scavenge.
